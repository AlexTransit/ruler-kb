# RulerKB

## Лазерная рулетка (Bluetooth) ⇒ ввод с клавиатуры (мм + Enter), Windows 10/11, без Mi Home и серверов Xiaomi.
Проверено на QWCJY001 

Сборка (нужен Go 1.22+):

```
go mod tidy
go build -o ruler-kb.exe .
```

Для использования рулетки совмесно с Mi Home необходимо получить токен рулетки. 
Получить токен можно с помощью:

https://github.com/PiotrMachowski/Xiaomi-cloud-tokens-extractor

**Привязать устройство с помощью полученного токена**

> ruler-kb.exe -mac 00:11:22:33:44:55 -token 1234567890abcdef1234567890abcdef12345678

в дальнейшем можно использовать локальную программу и Mi Home

## Прирязать рулетку к данному компьютеру 
запустите ruler-kb.exe.
Программа ⇒ сканирует Bluetooth устройства. Выбираете нужное устройство. Список сортируется по силе сигнала. Если в имени есть "xiao" программа спарится автоматически, создает config.json и запускается.

## Запуск
запустите **ruler-kb.exe**
выберите окно куда вводить данные измерений
производите замер. 

## Привязка рулетки к дополнительному компьютеру
Скопируйте config.json и ruler-kb.exe на другой компьютер. Запускате и пользуйтесь.

### Режим сопряжения 
(значок BLE мигает; если не мигает - сбросьте рулетку по инструкции).
Спаривание отключает рулетку от Mi Home или ruler-kb; прежний токен становится недействительным.
Само спаривание выполняется отдельным процессом (флаг -pair-only, служебный): BLE библиотека под Windows не освобождает ресурсы, пока процесс жив, поэтому подключаться нужно из другого процесса.

### config.json

можно создать вручную, например для уже имеющегося токена:

```
{
  "mac": "B4:60:xx:xx:xx:xx",
  "token": "24 hex-символа",
  "bind_key": "необязательно",
  "offset": 0
}
```

- mac - мак адрес устройства
- token - токен устройства
- offset - смещение в миллиметрах, положительный или отрицательный (например 25 или -40). Выводится замер + offset. Если поля нет, смещение 0. При повторном спаривании смещение сохраняется.

Ключи (все необязательны):


| ключ | параметр | описание |
| --- | --- | --- |
|-config | путь |другой файл конфигурации |
|-debug ||лог протокола
|-mac | AA:BB:…| MAC рулетки (переопределяет конфиг; при спаривании пропускает поиск)|
|-pair-only|| только спарить с -mac и перезаписать config.json (необходимо указать mac)|
|-print ||только печатать в консоль, без ввода с клавиатуры|
|-register||заново спарить рулетку и перезаписать config.json|
|-offset| число |смещение в миллиметрах, положительное или отрицательное(переопределяет конфиг)|
|-token| HEX |токен (переопределяет конфиг)|
|-vk ||вводить цифры виртуальными клавишами (если Unicode-ввод не принимается)|
